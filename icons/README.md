# SFW soil-life icons

15 single-colour line icons on a 512 x 512 grid, one stroke weight. Each keeps only the features that identify the
organism, taken from the fact-checked field guide (`../field-guide/SOURCES.md`).

Folders: `deep-green/`, `food-web-green/`, `white/`. Each icon as SVG (recolourable in Canva) and 1024 px transparent PNG.

| Icon | Identifying features kept |
|---|---|
| testate-amoeba | ovoid shell, rows of overlapping scales, toothed mouth, fine pointed pseudopods |
| testate-amoeba-mouth | mouth end-on: ring of toothed plates, scales around it |
| arcella | round shell from above, central round mouth, pore pattern |
| nematode | unsegmented body, rounded head, pharynx with basal bulb, pointed tail |
| fungal-hypha | even-width tube, cross walls, branches, rounded tips |
| flagellate | bean-shaped cell, short front flagellum, long trailing flagellum, nucleus |
| naked-amoeba | lobed pseudopods, nucleus, contractile vacuole |
| ciliate | Colpoda kidney shape, cilia all round, mouth notch, macronucleus |
| ciliate-cyst | thick double wall, cell inside |
| bacteria | rods and cocci |
| actinobacteria | thin branching filaments with spore chains |
| oribatid-mite | front shield, rounded back shield, 8 legs, two sensory hairs |
| springtail | antennae, 6 legs on the thorax, ventral tube, spring folded under the body |
| root-tip | root cap, root hairs above the tip |
| microscope | compound microscope |

Rebuild: `python3 build_icons.py`

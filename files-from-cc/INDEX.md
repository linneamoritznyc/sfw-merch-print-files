# Files from Claude Code: "Be the mycelium"

One design: a code-drawn mycelium network with "Be the mycelium / you want to see in the world" set in IM Fell English.
All files are PNG at full print resolution. Every file has a transparent background except the poster, which needs its
dark green background printed edge to edge.

- **Light ink** (mint and cream): for dark garments such as forest green.
- **Green ink** (Food Web Green to deep green): for light garments such as white, sand, sage and oyster.
